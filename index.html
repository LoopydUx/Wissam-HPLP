Low-pass and high-pass RC filters

Each filter is one resistor and one capacitor. Both see the same input. The low-pass output is the capacitor voltage. The high-pass output is the resistor voltage.

What is happening

Low-pass: H(jω) = 1 / (1 + jωRC). High-pass: H(jω) = jωRC / (1 + jωRC). With the same capacitor voltage at the start, low-pass output + high-pass output = input.
